# Activarea reCAPTCHA v2

Integrarea locală este pregătită în patru limbi. Activarea conturilor și testul cu un challenge real rămân de făcut. EmailJS acceptă numai reCAPTCHA v2: [documentație oficială](https://www.emailjs.com/docs/user-guide/adding-captcha-verification/).

1. În Google Cloud → Fraud Defense/reCAPTCHA → Keys, verifică înregistrarea existentă: tipul „Website • checkbox” corespunde v2 „Nu sunt robot”; „Website • score” corespunde v3. Nu este necesară o nouă înregistrare dacă cheia checkbox există. Pentru modificarea listei de domenii: acțiunile cheii → Edit key → Domain list → Update key. Domeniul este `psiholog-mariavaleriastanculea.github.io`, fără schemă, subdirector sau port. Pentru exercițiul local, adaugă `127.0.0.1` și `localhost`. Nu adăuga domeniul `.ro` până la confirmarea lui. Titularul contului acceptă personal orice acord afișat. Modificările setărilor și listei de domenii pot necesita până la 30 de minute pentru propagare; o eroare imediată după salvare nu dovedește o configurare greșită.
2. Copiază numai cheia publică „Site key” (numită „Key ID” în Google Cloud) în `.env.production.local`, la `VITE_RECAPTCHA_SITE_KEY`. În Actions, aceeași valoare publică va fi necesară ca variabilă de repository. Cheia secretă nu se introduce în chat, în Git sau în variabile `VITE_`.
3. În template-ul EmailJS „Solicitare site Valeria”, Settings, activează „Enable reCAPTCHA V2 verification” și introdu personal cheia secretă din aceeași înregistrare checkbox. În Google Cloud, aceasta se obține din Key details → Integration → Use Legacy Key sau Integrate with a third-party service or plugin. EmailJS acceptă integrarea v2 cu secret; implementarea actuală folosește api.js și validarea furnizorului, nu un backend propriu CreateAssessment. Salvează și verifică persistența. Conform opțiunii titularului din 4 octombrie 2026, „Do not save private data” este debifat: numele, emailul, mesajul și parametrii formularului se păstrează în istoricul EmailJS. Analytics rămâne dezactivat, iar destinatarul fix. Perioada de păstrare și accesul la istoric trebuie confirmate în notificarea de confidențialitate.
4. Reconstruiește candidatul. Formularul cere `g-recaptcha-response`; lipsa configurării îl face indisponibil, iar lipsa/expirarea tokenului blochează expedierea. EmailJS trebuie să facă validarea finală, independent de JavaScript-ul clientului. Un widget vizibil nu dovedește această validare.
5. Verifică respingerea unei cereri fără token și cu token invalid. Titularul rezolvă apoi personal challenge-ul real și trimite un mesaj tehnic identificabil. Confirmă primirea în Inbox/Spam și funcționarea Reply-To. Nu folosi date clinice.
6. Înainte de release, elimină originile/domeniile locale de test dacă nu mai sunt necesare. Lista EmailJS conține scheme/host/port, spre deosebire de lista Google. Pentru domeniul actual, păstrează `https://psiholog-mariavaleriastanculea.github.io`.

La opțiunea explicită a titularului din 4 octombrie 2026, scriptul Google se încarcă automat la deschiderea paginii Contact. Checkbox-ul este afișat într-un card cu stare de încărcare, verificare reușită, expirare și eroare/reîncercare. Explicația și linkul către informarea GDPR a cabinetului rămân vizibile în card, în acord cu tranziția Google la rol de împuternicit din aprilie 2026; emailul direct este disponibil. Widget-ul are format normal când spațiul permite și compact la 320 px. Tokenul rămâne în memoria componentei, este consumat la fiecare încercare, eliminat la expirare și pierdut la navigare sau la schimbarea formatului widget-ului după redimensionare; nu este salvat în storage sau în conținutul emailului.

`npm run test:contact` verifică și reCAPTCHA folosind scripturi/tokens fictive și cereri interceptate integral. Aceste teste nu rezolvă un challenge real și nu validează setarea serverului EmailJS. Documentează separat dovada reală în raportul de prepublicare. Referință Google: [render, expirare și reset](https://developers.google.com/recaptcha/docs/display).

Referințe actuale Google Cloud, consultate la 4 octombrie 2026: [terminologie și integrare cu servicii terțe](https://docs.cloud.google.com/recaptcha/docs/reconcile-legacy-terminology), [editare și propagare până la 30 minute](https://docs.cloud.google.com/recaptcha/docs/manage-keys), [validarea legacy pentru furnizori terți](https://docs.cloud.google.com/recaptcha/docs/verify), [domeniul localhost](https://docs.cloud.google.com/recaptcha/docs/troubleshoot-recaptcha-issues#localhost-is-not-in-the-list-of-supported-domains).
